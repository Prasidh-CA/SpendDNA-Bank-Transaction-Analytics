# SpendDNA - Industry Graded Minor Project

## Overview

SpendDNA is a banking transaction analytics system developed using Python, NumPy and Pandas.

The project performs:

- Transaction Parsing
- Vendor Extraction
- Category Tagging
- Spending Overview
- Monthly Trend Analysis
- Time-of-Day Analysis
- Z-Score Anomaly Detection
- Spending Archetype Detection

## Technologies

- Python
- NumPy
- Pandas

## Dataset

Six months of customer transaction history.

## Features

✔ Transaction Cleaning

✔ Vendor Identification

✔ Expense Categorization

✔ Spending Trends

✔ Financial Behaviour Analysis

✔ Fraud / Anomaly Detection
